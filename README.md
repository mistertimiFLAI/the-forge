# The Forge

The Forge equips young adults and early-career professionals to enter and lead in the marketplace with Christian character, conviction and capability.

This repository is the home for The Forge website. The first build should be created in Lovable using [`LOVABLE_BRIEF.md`](LOVABLE_BRIEF.md) as the source of truth.

## Core line

**Forged for the Kingdom. Built for the marketplace.**

## Principles

- Publicly, the brand is **The Forge** only. Do not mention TwC or a parent organisation.
- Build a serious, aspirational formation and work-pathway organisation, not a generic church or youth-charity site.
- Do not invent programme dates, team members, testimonials, figures, email addresses, partner names or impact claims.
